De dónde sale cada color

Del CSS que sirven las dos webs: HTML_TEMPLATE en medibot/Vision_MEDIBOT.py y HTML_PAGE en medibot/Pastillero.py. Revisado el 29 de septiembre de 2026.

No están los colores que el CSS de la cámara guarda para piezas que la página ya no tiene (título grande, subtítulo, pestañas, rejilla de posición, cruceta de movimiento y estadísticas bajo el vídeo): #9AA4AD, #FFB020 y el brillo rgba(0, 255, 255, 0.5). No se ven en ningún sitio. Tampoco entra la ventana de escritorio de Medibot (Tkinter): esta es la paleta de la web.

Si cambia el CSS de alguna de las dos webs, esta paleta hay que actualizarla a mano.
